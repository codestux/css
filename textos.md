# Textos

Podemos realizar configurações dos comportamentos dos textos que estão sendo exibidos no documentos HTML.

## text-transform

Mudar a apresentação do texto no documento. Existem diversos tipos.

```css
text-transform: uppercase;
```

## text-align

Alinha o texto na página HTML. Existem diversos tipos de alinhamentos.

```css
text-align: left
```

## text-ident

Configurar um espaço no início de cada linha de texto.

```css
text-ident: 33px;
```

## text-decoration

Exibe alguns ornamentos para o texto, como sublinhando, etc.

```css
text-decoration: underline;
```

## Altura de linhas

A propriedade line-height define a altura entre as linhas da página tomando como referência a altura da fonte. Exemplo:

```css
 line-height: 1.5; 
```
