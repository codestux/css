# Fontes

Podemos definir a fonte e suas características que precisamos nas nossas páginas.

## color

Define a cor da fonte.

```css
color: red;

color: #ffeedd;
```

## font-family

Define a família da fonte.

```css
font-family: Ubuntu;

font-family: Ubuntu, "Lucida Grande", sans-serif;
```

## font-size

Definindo o tamanho da fonte. Existem diversas grandezas de definição do tamanho da fonte.

```css
font-size: 54px;
```

## font-style

Definindo o estilo da fonte. Existem diversos estilos para aplicar nas fontes.

```css
font-style: italic;
font-style: oblique;
```

## font-weight

Definindo o peso da fonte.

```css
font-weight: bold;
```

## font-variant

Define variações para as fontes.

```css
font-variant: small-caps;
```
